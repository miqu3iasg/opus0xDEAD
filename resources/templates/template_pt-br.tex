% ============================================================
% TEMPLATE PARA ANOTAÇÕES DE ESTUDO EM LATEX (PORTUGUÊS)
% ============================================================
% Modelo de uso geral para converter anotações de estudo
% (originalmente escritas em Markdown ou em arquivos de código)
% para um documento LaTeX, para qualquer livro.
%
% Filosofia de design: corpo e capa em fonte padrão do LaTeX
% (Computer Modern), sem outros pacotes de fonte, sem cabeçalho,
% sem sumário. O corpo segue o modelo de um livro técnico clássico:
% texto simples, rodapé apenas com o número de página. A capa segue
% o modelo de uma folha de rosto simples de tese: papel branco,
% texto centralizado e um único desenho como única decoração. O
% desenho muda conforme a área de estudo (veja \coverArea nas
% variáveis do documento).
%
% Esta é a versão em português (pt-BR). Todo o texto visível do
% documento está em português. A versão em inglês é o arquivo
% template_en.tex.
%
% Instruções de conversão:
%
% - Ao converter anotações de Markdown para este arquivo, mantenha o
%   idioma original das anotações exatamente como escrito.
% - Não altere, reescreva ou traduza o conteúdo das anotações.
%   Apenas formate adequadamente para LaTeX (seções, blocos de
%   código, ênfases, listas etc.).
% - Comentários de código fazem parte das anotações e também devem
%   ser mantidos no idioma original.
% - Se as anotações do livro estiverem em inglês, use a versão em
%   inglês do template (template_en.tex), para que todo o texto
%   visível (capa, créditos, títulos fixos) siga o idioma das notas.
%
% Uso:
%
% 1. Copie este arquivo para começar as anotações de um novo livro.
% 2. Preencha os campos marcados com <...> na seção "variáveis do
%    documento" abaixo e escolha o desenho da capa com \coverArea.
%    É o único lugar que você precisa editar para configurar todo o
%    documento.
% 3. Se o livro não for sobre programação, o pacote listings e o
%    bloco de código podem ser removidos.
% 4. Duplique o bloco de seção para cada capítulo de anotações.
% 5. Compile com pdflatex (duas vezes, para as referências cruzadas
%    ficarem corretas).
